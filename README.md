# 30daysCodePerformanceOptimize

This is an repo teach you how to optimize cpp code getting high performance

### **一、阶段划分（4 周 + 2 天总结）**


| **阶段**              | **天数**    | **核心目标**                   |
| ------------------- | --------- | -------------------------- |
| **第 1 周：测量与工具链**    | Day 1-7   | 掌握基准测试、profiler、内存分析、汇编阅读  |
| **第 2 周：CPU 与内存优化** | Day 8-14  | 深入缓存、分支预测、数据布局、内存分配        |
| **第 3 周：编译器与多线程**   | Day 15-21 | 编译器优化、LTO/PGO、锁竞争、无锁编程     |
| **第 4 周：综合实战**      | Day 22-28 | 完整优化一个真实项目（如 JSON 解析器、矩阵库） |
| **收尾**              | Day 29-30 | 性能优化方法论总结、面试常见问题、结课项目      |


---



## **二、、30 天大纲草案（细化到每天）**



### **第 1 周：测量与工具链（基础能力）**

- **Day 1**：性能优化概论 + 环境搭建（Linux、perf、gcc/clang、CMake、Google Benchmark）
- **Day 2**：编写可靠的微基准测试：`DoNotOptimize`、防止编译器消除、统计稳定性
- **Day 3**：`perf stat` 与 CPU 性能计数器：IPC、cache-misses、branch-misses
- **Day 4**：`perf record` + `perf report`：热点函数定位与调用图分析
- **Day 5**：`perf annotate`：从 C++ 到汇编，理解编译器生成的指令
- **Day 6**：内存分析工具：`heaptrack`、`valgrind massif`、自定义分配器追踪
- **Day 7**：综合练习：分析一个开源小项目的性能瓶颈，提交分析报告



### **第 2 周：CPU 与内存优化（核心原理）**

- **Day 8**：缓存层次结构与 cache line：为什么局部性如此重要
- **Day 9**：数据布局优化：AoS vs SoA，结构体字段重排，冷热数据分离
- **Day 10**：循环优化：循环交换、分块、循环展开（编译器自动 vs 手动）
- **Day 11**：分支预测与无分支编程：`likely/unlikely`、查表法、位运算
- **Day 12**：内存分配优化：对象池、Arena、`std::pmr`、自定义 allocator
- **Day 13**：字符串处理优化：`string_view`、SSO、避免隐式转换
- **Day 14**：实战：优化一个图像处理或矩阵运算程序，记录 cache miss 变化



### **第 3 周：编译器与多线程（进阶能力）**

- **Day 15**：编译器优化选项详解：`-O0/-O2/-O3/-Os`、`-march=native` 的代价与收益
- **Day 16**：链接时优化（LTO）与 Profile-Guided Optimization（PGO）实战
- **Day 17**：看懂编译器优化：`constexpr`、`inline`、模板、RVO/NRVO 的实际影响
- **Day 18**：多线程性能基础：线程创建开销、任务划分、线程池设计
- **Day 19**：锁竞争与原子操作：`mutex` vs `atomic`，内存序选择
- **Day 20**：伪共享与缓存一致性：`alignas`、填充、`perf c2c` 检测
- **Day 21**：实战：多线程累加/哈希表优化，对比不同同步策略



### **第 4 周：综合实战与总结**

- **Day 22**：项目选题与基准建立（提供 2-3 个候选项目，如 JSON 解析器、正则引擎、粒子系统）
- **Day 23**：使用全套工具进行性能剖析，确定优化优先级
- **Day 24**：算法与数据结构层面优化（如替换容器、改进算法）
- **Day 25**：内存与缓存层面优化（数据布局、减少分配）
- **Day 26**：编译器与多线程层面优化（PGO、并行化）
- **Day 27**：性能回归测试与稳定性验证
- **Day 28**：撰写优化报告，对比优化前后数据
- **Day 29**：性能优化方法论总结：如何面对陌生项目快速定位瓶颈
- **Day 30**：面试高频性能问题解析 + 课程结业项目展示



## **如何利用这些资源构建30 天课程**

1. **以** `perf-ninja` **为骨架**，将它的实验拆分为每日任务。
2. **补充** `google/benchmark` **的使用教学**，确保学员会正确测量。
3. **引入** `compiler-explorer` 作为每日汇编观察工具。
4. **参考 CppCoreGuidelines 的 Performance 章节** 编写理论部分。
5. **基于** `CSAPP` **实验** 设计第 4 周的综合性项目。

GitHub 上素材丰富，完全可以支撑一个高质量的 30 天性能优化课程。如果你想进一步探讨如何整合这些资源，或者需要具体的课程设计建议，我可以继续帮你细化。
